# Lab 3 README
## Cleaning Messy Data   

### Clone repository
```
git clone https://github.com/accrawfish26/lab3.git
```
### Access and Cleaning Data
Use `script` file to open the RMarkdown in RStudio.   
Select Run -> Restart R and Run All Chunks
The script will read the messy sample and sequence files and have them saved
> Note: RStudio needs to be set at the root directory of the cloned repository  
> Note: The output of script will be saved in the output file

### AI Usage and Comparison
The `AI_USAGE` contains list of errors resolved or discussed to address.  
The `AI_USAGE` contains the promts used to generate AI version of the cleaned data.
